# Brescia Group — Landing Page

Landing page para Brescia Group, estudio de content & marketing para hoteles boutique y destinos turísticos.

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Framer Motion 12

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## Build para producción

```bash
npm run build
npm start
```

## Configuración

Los datos de contacto están centralizados en `lib/constants.ts`.
